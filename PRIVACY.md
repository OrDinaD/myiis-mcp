# Privacy Policy for MyIIS MCP

Last updated: September 6, 2026

## 1. Overview
MyIIS MCP ("the Plugin") is an open-source tool developed by Vladislav Vasilevskiy to provide access to public schedule information from the Belarusian State University of Informatics and Radioelectronics (BSUIR / БГУИР) within ChatGPT.

## 2. Information We Access and Process
- The Plugin processes only user-specified search parameters (such as group numbers, teacher names, or dates) necessary to query the BSUIR public API.
- All requests are forwarded directly to the official public BSUIR IIS API (`https://iis.bsuir.by/api`).

## 3. Data Storage and Retention
- **No Personal Data Collected:** The Plugin does not collect, store, or profile any personal user data.
- **No Databases:** The Plugin operates completely stateless without a user database.
- **No Tracking:** We do not track user identities, session histories, or conversations.

## 4. Third-Party Services
- The Plugin interfaces solely with the public BSUIR IIS API (`https://iis.bsuir.by/api`) to retrieve educational schedules.
- Hosting is provided via Cloudflare Workers, which processes incoming requests in accordance with Cloudflare's privacy practices.
